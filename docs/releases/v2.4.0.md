# v2.4.0: @x402 2.26 on our own handshake, Astra and Fable on premium, effort on the Messages wire, and a router that indexes

Every merge since v2.3.0 (2026-09-02 to 2026-09-18). Each change was verified against production the day it merged; the two live proofs still owed before this tag are listed at the end.

## Buyers
- **Two more frontier models on the premium tier.** `openai/gpt-6-astra` and `anthropic/claude-fable-5.1` are admitted at `$0.50` on `/v1/premium/chat/completions` and the Messages and Responses wires ($10/$50 headline, 1M context, reasoning mandatory). A 4k-char prompt leaves about 6k output tokens on either under the margin clamp.
- **`effort` on the Messages wire.** Top-level `effort` (low, medium, high, xhigh, max) is the depth control on Claude 4.7+ (Opus 5, Sonnet 5, Fable 5.1), validated against the model's own effort list from `/v1/models` and refused with that list; older Claude keeps `thinking.budget_tokens`. `speed` other than `standard` is refused (the priority endpoint bills twice list). Fable 5.1 refuses a forced `tool_choice` with the fix named; GPT-6 Astra refuses `temperature` and `top_p` instead of the upstream dropping them silently.
- **Cost rows read the dearest endpoint.** Every `MODEL_COST` row now carries the dearest default-tier endpoint a call can route to, not the catalog headline (gpt-5.6-sol's regional endpoints bill 2.75x its headline). The live model guard reads each admitted model's endpoint list on every run and fails on any tier default or OpenClaw primary pick that carries an upstream expiration date.
- **Transcription.** `/api/transcribe` moved off `gpt-4o-mini-transcribe` onto `gpt-transcribe` ahead of its 2027-02-26 shutdown; the cap is 4 minutes (was 5) so the worst case stays under 70% of the price. The two tiers now differ only in cap and price. `/api/tts-lite` caps text at 800 chars (was 2,000) for the same reason: its model gained a dearer upstream endpoint.
- **Chain reads by the RPC verb.** `/api/chain/<verb>` maps 35 RPC verbs and raw `eth_*` names onto the tools that already serve them, with five new reads (`chain-nonce`, `chain-storage`, `chain-pending`, `chain-total-supply`, `chain-erc1155-balance`); `GET /api/chain` is the free index. A contract revert is a 422 about the caller's address, not a 502.
- **Receipts and verdicts.** `POST /api/attest` writes an Ethereum Attestation Service attestation on Base for a settled call (slug, response digest, settlement tx). `POST /api/feedback` records one good or bad verdict per settlement tx, writable only by the wallet that paid; `GET /api/feedback/summary` is counts only.
- **Router.** `/api/route` answers from a candidate index instead of a full scan of the seller pool, with the ranking byte-identical to the full scan on a prod-sized golden. Exa search categories are validated against the current list; Polymarket price history reads the Data API.
- **`/x402-test`** (`/conformance`, `/debug`): the refusal diagnostic, with the full reason table derived from the classifier itself.

## Sellers
- **A migrated seller is listed once.** A verified succession retires the predecessor from the index, the router pool and the seller counts while its successor is present; the old origin's detail page says where it went. Retirement is gated on the served-marker proof only, re-verified every crawl, and backs itself out if the successor dies.
- **A price that went to zero is read as zero.** A GET route that answers 200 with no paywall retires a learned or snapshot price; an explicit re-registration re-asks every priced row that is not the origin's own declaration.
- **Payment annotations.** The crawler reads every OpenAPI payment-annotation dialect through one reader, and a manifest price published as an object (`{amountUsd, payTo, ...}`) is read as a price.
- **Leaderboard.** `GET /api/leaderboard` defaults to `include=external`; the host's own row carries `self: true` on the full board.
- **agent402-tollbooth 0.10.1.** The published CLI runs through the npm bin symlink again (0.10.0 exited 0 and served nothing when started with `npx`).
- **Seller dossier.** `POST /api/seller-dossier {origin}` ($0.05): everything the index holds about one origin, with per-row price provenance and the router's own eligibility verdict.

## Operators
- **@x402 2.22.0 to 2.26.0** on the server, the Stellar facilitator and `agent402-mcp`. The vendor client's spend controls (a $1 pegged-assets cap, default on since 2.23) are switched off on every client we build; our own bounds already hold the line. The facilitator handshake is driven by `src/x402-boot-init.js`: a facilitator that is dead at boot leaves paid routes answering 500 until a retry succeeds, and the process stays up. Every buyer workflow's client pin moved to 2.26.0.
- **@solana/kit 5.5.1 to 8.3.0** (token 0.16.1, compute-budget 0.18.1) with overrides for the kit-5-peered program packages `@x402/svm` still depends on, pinned against svm's own import list.
- **Settle fallback order.** Solvador first on the networks it advertises (free tier), then PayAI (gas x 1.3 in prepaid credits), Solvador as the last resort elsewhere. The heartbeat watches PayAI's 1,000-credit lifetime allowance per receiving wallet.
- **Base image on Node 22.23.2** (the 2026-07-29 security release); every workflow runner pinned to `ubuntu-24.04`. mppx 0.9.3.
- **Guards added:** wallet-only tools consult the settle-failure breaker before the handler (per wallet only); the copy guard shape-matches four classes of absolute claim (determinism, custody, seller proof, tested-before-deploy) across 392 surfaces and pins both directions; retired price figures are swept across 354 surfaces; the CoinGecko bucket is 80/min and CI no longer spends the production key.
